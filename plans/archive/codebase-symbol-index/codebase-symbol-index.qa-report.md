## Notes

### AC9 implementation — verified correct

The Round 1 finding (AC9 unmet) has been resolved. The Step 4 pre-step is a new bash block that:

1. Runs `git diff --name-only HEAD` to get changed files.
2. Runs the scanner in `--format json` mode.
3. Uses an inline `python3` snippet with environment variables to safely extract import edges where `source_file` is in the changed-file set.
4. Formats results as a markdown table and stores in `$IMPORT_GRAPH_DATA`.
5. Injects `$IMPORT_GRAPH_DATA` into the Step 4a code reviewer prompt under `**Import graph (blast radius):**`.

Graceful degradation works: if scanner is unavailable or no changed files exist, `$IMPORT_GRAPH_DATA` is empty and the section shows "No import edges found for changed files." or "Import graph unavailable."

### AC7/AC8 audit events — verified correct

Both skills now emit `scanner_invocation` events when scanner output is non-empty, containing: `scanner_version`, `parser_mode`, `file_count`, `symbol_count`, and `output_sha256`. This satisfies the Repudiation mitigation requirement from the STRIDE analysis.

### Non-blocking observations

1. **`datetime.utcnow()` deprecation**: `scripts/codebase-scanner.py` uses `datetime.datetime.utcnow()` (deprecated since Python 3.12). Skills suppress stderr via `2>/dev/null`; no runtime impact. Will need cleanup before Python 3.14 removes the function.

2. **Binary/oversized file integration test coverage gap**: `test-integration.sh` does not include tests for binary file detection or `--max-file-size` enforcement. The self-test (`--self-test`) covers these cases and is itself integration-tested as Test 36. Not a blocking issue — self-test is authoritative.

3. **`--no-cache` not independently tested**: Test 33 uses `--no-cache` as a flag in a combined test rather than testing the cache bypass behavior in isolation. Minor.

4. **Skill validator warnings**: Both modified skills produce one validator warning for "Timestamped Artifacts" — pre-existing pattern, not introduced by this change. Both pass validation.
